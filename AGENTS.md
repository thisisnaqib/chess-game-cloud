# Project Development Guidelines

## Design Guidelines
- Always refer to `design.md` before creating or modifying UI components.
- Follow the specified colors, typography, spacing, layouts and components.
- Maintain consistent UI/UX throughout the application.
- Do not introduce unrelated design styles.

## Development Guidelines
- Inspect existing code before making changes.
- Follow the existing project architecture.
- Write clean, maintainable and reusable code.
- Avoid unnecessary dependencies.
- Do not overwrite existing functionality without understanding its purpose.
- Test functionality after implementing changes.

## Development Workflow
- Plan before implementing.
- Work incrementally, one feature at a time.
- Explain important architectural decisions.
- Report any errors or incomplete functionality honestly.
